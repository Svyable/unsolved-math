# Primary-source scope — theory lane

Accessed 2026-08-28. [AIM workshop questions](https://aimath.org/pastworkshops/projectiveA1problems.pdf),
dated May24,2014, page3 Question9, asks about a Serre spectral sequence for
Morel's A1-homology. The page was rendered and visually inspected because
the text extraction damages its symbols. The exact short transcription,
PDF hash and render hash are in source-provenance.json. This supports the
parent agenda only, not the imported finite-group refinement or status.

[Brown, Lectures on the Cohomology of Groups](https://pi.math.cornell.edu/~kbrown/papers/cohomology_hangzhou.pdf),
Section5.2 Definition5.1, printed page30, defines ordinary equivariant homology
using a projective resolution tensored with cellular chains. Example5.2(c),
page31, identifies it with quotient homology for free actions. Pages32–33
give the group-homology spectral sequence. These are ordinary statements;
their transfer to motivic homology is not established here.

[Hatcher, Algebraic Topology chapter1](https://pi.math.cornell.edu/~hatcher/AT/ATch1.pdf),
Proposition1.40, printed page72, requires the covering-space action condition
and identifies the quotient of fundamental groups. Use it only for the free
rotation example, not to discard stabilizers in nonfaithful actions.

[Hatcher chapter5](https://pi.math.cornell.edu/~hatcher/AT/ATch5.pdf),
Proposition5.2, printed page525, relates the limiting page to a filtration's
successive quotients. It does not assert a canonical direct-sum abutment.
Our concrete extension calculation is derived separately.

No full copyrighted source or rendered page is redistributed. The repository
retains links, locators, hashes and our bounded analysis only.
